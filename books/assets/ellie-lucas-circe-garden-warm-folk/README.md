# Ellie、Lucas 與喀耳刻的魔法花園

本書共有 51 張 3:2 圖像：封面 `page-00`，故事頁 `page-01` 至 `page-50`。原始圖為 PNG，網頁執行版為 1536 × 1024 WebP（quality 86）。

## 視覺與角色鎖定

- 統一採用「牙齒說話樣本風格」：溫暖 Decorative Folk Flat、柔和不透明水粉、奶油紙張顆粒與手作邊緣。
- Ellie：四歲東亞女孩，齊瀏海深色短鮑伯頭；珊瑚紅兒童希臘式 chiton、低彩度藍綠腰帶、棕色涼鞋。
- Lucas：兩歲幼兒，圓潤嬰兒臉、頭大身短、四肢短；柔軟深棕髮，顏色比 Ellie 稍淡；粉藍短 chiton、暖象牙色繩腰帶。Lucas 頭頂固定只到 Ellie 上胸，不能畫成學齡兒童或成熟少年。
- 喀耳刻：約為 Ellie 身高 2.2 倍，長而深色的波浪髮、芥末金長袍。
- 赫密士：象牙色短袍、珊瑚披肩、帶翼涼鞋；不可與喀耳刻混用造型。
- 三隻豬與復原後旅人的配件一一對應：深藍綠圍巾＝領航員、象牙色斜背袋＝廚師、芥末腰帶＝水手。
- 三位復原旅人皆為成人，身高差控制在 5% 內；復原前後不得忽大忽小。

權威角色比例參考為 `character-lock-v2.png`。後半段 P15–P50 依此鎖定重製；場景依故事順序從封閉花園、森林、宮殿談判、復原、港口到海上連續演進。
