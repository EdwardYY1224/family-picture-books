# City Sound Detective audio

These runtime recordings replace the game's former synthesized approximations.
Only the short segment configured in `games/js/engine.js` is played.

| Runtime file | Sound | Source and license |
| --- | --- | --- |
| `bus-horn-source.ogg` | MAN city-bus horn | Work With Sounds / Dusan Oblak, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:WWS_CityBusMANSG220horn.ogg), CC BY 4.0 |
| `ambulance-siren-source.ogg` | Alarm/siren | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Alarm_or_siren.ogg), public domain |
| `dog-bark-source.ogg` | Dog bark | George Shuklin, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:George_vuf_1996.ogg), public domain |
| `bike-bell-source.wav` | Bicycle bell | bsumusictech, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bsumusictech_bike-bell.wav), CC0 1.0 |
| `train-horn-source.ogg` | Adelaide Metro A-City 4000 train horn | Cityedit14, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:4000_class_train_horn.ogg), CC BY-SA 4.0 |

The bus and siren files are trimmed at playback to isolate a clear, child-friendly
sample. The dog bark is repeated twice with a short pause. Volume is reduced on
the louder horns and siren. No source recording contains a child's voice or image.
