# Summer Camp English Adventure

Public, child-facing four-week English course derived from parent-provided
lesson recordings.

The source MP3 files and raw machine transcripts are intentionally excluded
from this public repository. Listening buttons use the browser's built-in
English speech synthesis with cleaned learning targets.

The four WebP sprite sheets are original generated learning illustrations in
the project's locked warm folk-gouache style. They contain no text, logos,
watermarks, or private identity references.
